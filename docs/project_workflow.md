This project follows a complete end-to-end business analytics workflow for customer churn analysis and retention reporting.

---

# 1. Data Collection

The Telco Customer Churn dataset was collected and imported for analysis.

Dataset includes:
- customer demographics
- subscription details
- billing information
- churn indicators
- customer tenure metrics

---

- handling missing values
- removing duplicate records
- datatype conversion
- feature engineering
- churn encoding

Python and SQL were used for cleaning workflows.
